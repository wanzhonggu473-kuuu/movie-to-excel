# Security and privacy

Movie to Excel is designed to keep the viewing archive on the user's computer. The project does not require an account and does not include analytics, telemetry, or a product-owned cloud database.

Movie titles and public metadata may be sent to internet search services for verification. A poster or screenshot should be transmitted to an external identification service only after the user understands that boundary. Personal ratings, private notes, and the completed workbook must remain local unless the user explicitly chooses to share them.

Do not publish a security vulnerability in a public issue. Contact the repository owner privately through the security reporting method configured on GitHub.
