# Contributing

Thanks for helping improve Movie to Excel. Keep changes aligned with the project's local-first purpose: the workbook belongs to the user, personal ratings and notes stay local, and internet access is used only to verify public movie metadata or identify a supplied poster.

Before opening a pull request:

1. Keep `电影数据库` as the single source of truth.
2. Preserve all three presentation views and existing user-controlled settings.
3. Do not add accounts, analytics, cloud storage, public profiles, likes, feeds, or social rankings.
4. Use established Chinese director names for Mainland China, Hong Kong, and Taiwan productions; use full English or romanized names elsewhere.
5. Run the workbook verification script and inspect the changed sheets visually.
6. Do not commit personal movie archives, temporary previews, or generated inspection files.

Bug reports should include the movie title, release year, expected region, affected sheet, and a screenshot with private notes removed.
